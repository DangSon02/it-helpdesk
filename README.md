# IT Helpdesk

Hệ thống báo cáo và xử lý sự cố CNTT cho doanh nghiệp.

## Trạng thái

🚧 Đang phát triển — Mốc 1: giao diện tĩnh (HTML/CSS).

## Công nghệ

- Frontend: HTML, CSS, JavaScript thuần
- Backend: Java 21, Spring Boot 3 (dự kiến)
- Database: MySQL 8 (dự kiến)

## Cách chạy

1. Clone repo: `git clone https://github.com/<tên>/meeting-room-booking`
2. Mở thư mục bằng VS Code.
3. Mở `frontend/login.html` bằng Live Server.
